Noun + の + まえに

ENNoun の まえに - see 〜まえ

JA「Nounの まえに」は 「その ことの まえ」と いう いみです。「ごはんの まえに 手を あらいます」。

Explanation

Noun-frame instance of まえ ('before'): noun + の + まえ(に). Parent entry 〜まえ covers both noun-frame and verb-frame uses; this entry isolates the noun-frame for syllabus sequencing. The trailing に is the time-locative particle (に / 〜に) attaching to the まえ phrase as a whole.

Examples

JAごはんの まえに てを あらいます。
ENI wash my hands before meals.
JAテストの まえに 本を 読みます。
ENBefore the test, I read a book.
JAばんごはんの まえに 休みました。
ENI rested before dinner.
JAテストの まえに たくさん べんきょうしました。
ENI studied a lot before the test.
JA三日 まえに 来ました。
ENI came three days ago.
JAドアの まえに ねこが います。
ENA cat is in front of the door.
JAじゅぎょうの まえに しゅくだいを します。
ENBefore class, I do my homework.
JAしごとの まえに、 コーヒーを のみます。
ENBefore work, I drink coffee.
JAかいぎの まえに しりょうを よみます。
ENBefore the meeting, I read the materials.
JAにじの まえに きて ください。
ENPlease come before 2.

Common mistakes

✗ ごはん まえに てを あらいます。
✓ ごはんの まえに てを あらいます。
Noun + まえ requires の. (Verb-plain + まえに does NOT take の: 食べる まえに.)
✗ ごはんの まえで てを あらいます。
✓ ごはんの まえに てを あらいます。
Noun + の + まえに = 'before [noun]' (using に). The form まえで doesn't fit: まえ takes に as its companion particle (parallel to あと + で which is the after-companion).
✗ ごはんに まえに てを あらいます。
✓ ごはんの まえに てを あらいます。
Noun + の + まえに. The connector before まえに is の. に would mean 'to the meal', changing meaning. For 'before meals', use ごはん + の + まえに.

Wrong / corrected pairs

✗ がっこうまえに、 たべます。
✓ がっこうのまえに、 たべます。
Noun + まえに needs の.
✗ がっこうのまえで、 たべます。
✓ がっこうのまえに、 たべます。
Context: intent: before going to school. まえに for "before (time)"; まえで is a different meaning ("in front of").
✗ にじのまえで、 きました。
✓ にじのまえに、 きました。
Context: time intent. Time-before takes に, not で.
