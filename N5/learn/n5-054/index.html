いくつ

EN'how many' (general counter / age)

JA「いくつ」は かずを ききます。としを きく ときにも つかいます。

Explanation

いくつ asks 'how many' using the native ひと-counter system. Also used to politely ask age (especially of children).

How to use

使い方
FormExample
How many (general)りんごは いくつ ありますか。
How old (polite for child)おいくつですか。

Common mistakes

✗ 何個ありますか。 = いくつありますか。
✓ いくつ is general; specific counters need 何個/何冊/何台.
いくつ is the generic counter-question word; for objects with a known counter, native speakers prefer the specific 何+counter form. Using いくつ for books or cars sounds learner-Japanese.
✗ りんごは いくらですか。
✓ りんごは いくつ ありますか。
Context: when asking quantity, not price. いくつ = how MANY (count); いくら = how MUCH (price). For 'how many apples are there?', use いくつ + あります. いくら would ask 'how much do the apples cost?'

Register variants: both forms are correct

These forms differ in register, formality, or pragmatic context, not in grammaticality. Pick by context.

confirmation-seeker (〜ね) りんごは いくつ ありますね。
neutral question (〜か) りんごは いくつ ありますか。
Both ね-ending and か-ending are grammatical. The choice is PRAGMATIC, not grammatical: ね seeks confirmation from a listener who is presumed to share the speaker's view ('it's X, right?'); か is a neutral question ('is it X?'). Neither is wrong; pick based on the speaker's pragmatic stance.
neutral polite: common age question おとうさんは いくつ ですか。
honorific: お-prefix elevates the question おとうさんは おいくつですか。
Both forms are grammatical. The お-prefix on いくつ is honorific (美化語/尊敬). When asking about a senior's age, the お-prefixed form is preferred but the plain form is not ungrammatical.

Wrong / corrected pairs

✗ いくつ ですか。
✓ いくらですか。
Context: asking price. いくつ for count of items / age; いくら for price.
✗ りんごは いくつに ありますか。
✓ りんごは いくつ ありますか。
いくつ takes no particle.
